# Xue Fanhao personal homepage

A dependency-free static academic profile inspired by the AcademicPages layout referenced in the design brief. The identity is set to **Xue Fanhao / xuefanhao**.

## Preview

Open `index.html` directly in a browser. No build step or local server is required.

## Pages

- `index.html` - English profile and biography
- `chinese_intro.html` - Chinese profile page
- `research.html` - research directions
- `teaching.html` - teaching profile
- `people.html` - collaboration and group structure
- `gallery.html` - research gallery
- `join.html` - recruitment and contact information

## Customize

1. Replace `assets/profile.svg` with your own portrait. Keep a square source image for the circular crop.
2. Search all HTML files for `Xue Fanhao`, `xuefanhao`, `xuefanhao@example.com`, and placeholder profile links.
3. Replace the sample biography, education, research, people, and gallery copy with verified information.
4. Replace the gallery SVGs in `assets/` with WebP or AVIF photographs when your own images are ready.
5. If the site is published as a project page instead of `xuefanhao.github.io`, use relative links consistently.

## GitHub Pages

The repository is named `xuefanhao.github.io` under the authenticated GitHub account `fengxue-github`. Its project Pages URL is:

`https://fengxue-github.github.io/xuefanhao.github.io/`

Enable **Settings → Pages → Source: GitHub Actions**. The included workflow publishes the static files directly without a build.

The site can also be hosted on Cloudflare Pages, Netlify, or any web server that serves static files.
